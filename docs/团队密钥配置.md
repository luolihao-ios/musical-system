# GitHub 组织共享 Apple API 密钥

2026-10-24 经用户授权，统一使用 `luolihao-ios` 组织级 Actions Secrets，不再由音乐播放器仓库保存同名覆盖值。

| 组织密钥名 | 用途 |
| --- | --- |
| `APP_STORE_CONNECT_API_KEY_ID` | App 管理权限团队密钥的 Key ID |
| `APP_STORE_CONNECT_ISSUER_ID` | 同一个 Apple 开发团队的 Issuer ID |
| `APP_STORE_CONNECT_API_KEY_BASE64` | `.p8` 私钥文件的 Base64 编码 |

本次更新保留原有两个项目的访问权限，并加入当前播放器，访问范围为所选仓库，而非所有仓库：

- `iphone-Front-and-Back-Camera-Recording`
- `iPhoneVpnclient`
- `musical-system`

播放器的三个发布工作流已统一引用上述名称。新增项目若要复用，必须由组织管理员把该仓库加入这三项组织密钥的访问范围，并使用相同的密钥名称。只适用于同一 Apple 开发团队；不同团队不能直接共用 Issuer ID 与密钥组合。

仓库级同名 Secret 会优先于组织级配置，因此已删除播放器仓库的 `APP_STORE_CONNECT_ISSUER_ID` 同名覆盖项。旧分支仍使用不同名称的 `APP_STORE_CONNECT_KEY_ID` 和 `APP_STORE_CONNECT_PRIVATE_KEY_BASE64`，暂时保留作兼容，它们不会覆盖新工作流使用的组织名称。待所有仍在使用的分支完成迁移后，再移除这两项兼容配置。签名证书、描述文件和其他组织密钥保持不变。其他仓库若有自己的同名覆盖项，也不会因组织密钥更新而自动切换；本次不擅自修改其他项目。

验收：组织三项均为 `selected`，访问仓库数量均为 3；当前分支通过 GitHub Actions 读取组织密钥，并成功连接 Apple 读取商店版本和截图组（运行 `40073197560`）。组织密钥不能回读明文，验收使用配置元数据和实际 API 认证，不输出私钥。

私钥只从用户指定的本机文件读取，经标准输入传给 GitHub，禁止输出、写入代码或日志。Apple 密钥与 GitHub 组织管理授权是两套独立权限。密钥更新不触发 App 发布，不改变构件号。
