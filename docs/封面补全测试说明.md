# 现有来源后台封面补全测试说明

更新日期：2026 年 10 月 21 日。适用分支：`codex/aiyue-greenfield`。

## 本轮确认的行为

- 百度搜索保留源码，但不注入应用、不发查询，也不展示 API Key 输入界面。无需用户申请任何密钥；没有新增 Cloudflare 或其他后端。
- 本地音频先完成导入，立即显示内嵌、同名图片或程序化封面并可播放。后台顺序处理歌曲，不让导入、播放等待联网。
- 只有缺图或程序生成图允许自动替换；内嵌、同名伴随图片、自选图片和此前下载的真实封面保留。收到延迟结果前重新读取记录，避免复活已删除歌曲、覆盖期间手动修改的封面。
- 成功仅更新图片路径与播放队列元数据，不重新加载音频，不改变播放位置。结果图片保存为 `ImportedMusic/<编号>/artwork-online.jpg`，同目录 `source.json` 保存实际来源与候选地址，不改写用户原 MP3 标签。
- 原有 LRC 照常读取；歌词仍仅在播放页点击“查找歌词”时查询，不随导入自动联网。

## 来源、语言优先级与匹配

具备图片返回能力的现有来源全部纳入候选链路：网易、QQ、酷狗、iTunes、MusicBrainz/Cover Art Archive、Jamendo、Internet Archive。不是每个来源都保证可用或有结果；找到可用图片即停止其余请求，不为了“全部调用”浪费流量。

中文歌优先网易、QQ、酷狗；英文歌优先 iTunes、MusicBrainz、Jamendo。每批最多三个来源，未命中再交叉回退其余来源。Internet Archive 仍限定现有开放音乐集合，不进行任意全网抓图。

先清理括号内 Live、Cover、现场、翻唱、版本等说明，用歌名宽搜；标点差异不影响匹配。候选中优先同歌名，再提高同歌手、同专辑分数，不以音频时长拒绝封面。未获得歌曲图且预算允许时，再以首位歌手搜索其专辑封面，保存来源时标注为歌手专辑替代。多个歌手不要求完整字符串逐字一致。

LRCLIB 是歌词源，App Store lookup 是版本检查，均不作为封面来源。QQ、酷狗结果没有许可标记不影响本轮仅查询封面的逻辑，但不能据此声称取得了素材通用商用授权。

单首目标约五秒查找窗口，已有候选的下载最多再收尾三秒，整体不无限等待；一次只处理一首歌。失败的一小时内不自动重复，手动“重新查找缺失封面”可重试。成功图在会话内按歌名/歌手/专辑复用，最多缓存十六项，避免同名歌不同专辑串图。某来源鉴权失败或额度异常时暂时冷却五分钟，其余来源继续。

## 本次定位到的真实断点

1. 早期普通文件导入默认没有在线服务，后台补全又只从交接链接触发。
2. 生成图使图片路径非空，被旧逻辑当作已有真实封面。
3. 旧查询对封面沿用了歌词的版本、时长严格匹配。
4. 网易搜索实际返回 `album.picId`，不一定包含 `album.picUrl`；只读搜索返回字段会丢掉已存在的封面。本轮追加网易歌曲详情 `https://music.163.com/api/song/detail/` 取得实际图片地址。
5. QQ 普通 JSON 不能无条件删除最后一个字符；本轮封面适配器分别解析 JSON 与 JSONP。酷狗只有专辑编号时尝试同平台专辑详情 `/api/v3/album/info`，连接失败仍回退，未关闭 TLS 校验或绕过平台登录。

## 手机测试与日志

1. 导入一批中文歌、英文歌，带 Live/Cover 的文件可一起导入。观察本地入库立即完成，生成图先显示。
2. 在搜索期间播放、拖动进度或切歌，观察找到的封面原位更新，音乐不重启。
3. 对已入库的生成图，在“设置 → 封面搜索设置”点击“重新查找缺失封面”；可在该页暂停后台查询。
4. 没有找到图片时，从该页“导出封面查询日志”，或在“文件 → 我的 iPhone → 爱乐之城”取出 `music-cover-diagnostics.log`。

日志记录歌曲、来源优先级、HTTP 主机/路径/状态、返回条目与可用候选数量、图片下载/解码失败、命中与保存等阶段；轮转上限约 2MB，并保留上一份。不会记录百度密钥。歌曲文字和错误详情只用于本地排查，分享日志前可自行脱敏。

## 验证边界

本机真实探测：《明天你好》的网易搜索返回无 `picUrl`，详情返回有效封面，图片请求 HTTP 200、170688 字节；iTunes 英文关键词请求也返回了封面字段。该结果只证明当前电脑网络与上游链路，不能代替 iPhone 真机效果。

同一轮探测中，QQ 原搜索接口 HTTP 500，酷狗 TLS 连接失败，Jamendo 默认测试应用返回已挂起。它们已被纳入回退，但不能把“写了适配器”报告成“这些服务都实测成功”。Jamendo 正式应用 ID 未配置；公开发布前仍应核实各来源的接口及图片使用范围。

自动化回归覆盖：中英文来源优先级及交叉回退、无百度请求、Live/标点/多人歌手宽匹配、网易缺图片字段的详情补查、来源失败不阻断其他来源、歌手专辑替代、立即导入/延迟替换、真实封面保护、删除竞态、播放状态保持。实际 iOS 测试与构建结果以 GitHub Actions 为准。
