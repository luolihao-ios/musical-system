# 参考图播放器改版实施清单

目标：实现参考图的浅色首页、音乐库、搜索、我的及三种播放外观，同时保留现有播放、收藏、导入和歌词能力。

- 首页：使用真实开放目录。查询热门（下载量排序）、最近收录（收录时间排序）、主题（风格关键词），通过专辑元数据取得曲目和封面；今日推荐从可播放结果选取。歌单和风格电台复用现有播放器队列，无数据时不伪造。缓存与本地音乐库隔离。项目内 Jamendo 测试凭据返回停用，当前以可用的 Internet Archive 目录作为首页来源。
- 音乐库／我的：参考图的四个底栏入口。音乐库与「我的 → 我的音乐」指向同一份本地资料，收藏与设置移到「我的」，首页不放本地曲目。搜索保留在线结果和下载，加入本地搜索。
- 播放：封面、黑胶、复古转盘样式共享一个播放状态；保留歌词与播放器手势，保存样式及主题偏好。实现定时暂停，音效入口只呈现实际支持的音量调整，不把它叫均衡器。素材图的版本号不改。
- 验证：用目录查询、队列和定时器测试固定回归，更新三设备素材导航。Windows 运行可用检查，原生构建、设备画面和上传单独标记。

实施结果：Windows 可用脚本 84 项通过，目录七组查询和音频、封面各一项抽样验证通过。修正了「播放全部」误暂停、在线队列换曲缺封面、专辑搜索返回错误首曲及最近播放失去入口。原生测试已添加，尚未运行；未发布。
