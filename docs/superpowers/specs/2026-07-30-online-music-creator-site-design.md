# 在线音乐搜索与 AI 写歌网站设计

## 目标与范围

在现有本地音乐播放器规划之外，新建一个独立的 Web 音乐站。网站提供合规的联网音乐搜索、统一播放器、用户注册登录，以及按点数付费的 AI 完整歌曲生成。它不替换、不修改，也不依赖 Windows/iOS 本地播放器。

首版的重点是完整创作与试听闭环：用户注册，选择模型并提交创作任务，系统根据任务状态冻结或扣除点数，生成完成后在个人作品库中完整试听。点数购买页面与订单数据模型会先完成；微信支付与支付宝的真实下单、回调和发点在后续接入。

## 合规边界

- 联网搜索只使用公开或获得授权的来源，例如 iTunes Search API、Jamendo 或之后接入的等价授权服务。
- 外部曲目只播放来源允许的预览，或跳转到来源平台播放完整版；网站不抓取、下载、转存或提供受版权保护的完整外部音频。
- AI 完整音频只对调用服务商成功生成的作品提供站内试听，并按服务商条款决定下载和公开分享的权限。
- API 密钥、第三方服务请求和支付凭据全部留在服务端，绝不发送到浏览器。

## 系统架构

网站由独立前端和后端服务组成：

- 前端：主页、搜索、播放器、AI 写歌工作台、认证、账户、作品库和购买点数页面。
- 后端 API：认证会话、用户资料、点数账本、订单、创作任务、作品元数据与搜索代理。
- 任务执行层：按服务商路由创建生成任务、轮询状态、保存可用试听地址和错误原因。
- 服务商适配层：统一 `createJob`、`getJobStatus`、`cancelJob` 与作品规范化接口；首批预留 Suno、Udio、Replicate 等常见服务商的可替换适配器。
- 数据存储：用户、会话、点数余额/流水、订单、创作任务、AI 作品、收藏及播放历史。音频本体使用服务商授权地址或对象存储引用，不作为外部歌曲缓存。

管理员配置哪些服务商可用、每个模型的点数价格、每种服务的必要输入字段。服务商适配器不可用时，前端不显示其创建入口。

## 用户流程和点数规则

1. 用户注册或登录后获得账户与个人作品库。
2. 在 AI 写歌工作台选择服务商/模型，填写主题、曲风、情绪、语言、时长和可选歌词，提交前显示价格、余额与预计时间。
3. 后端原子地校验余额，创建任务并冻结对应点数，再将任务交给适配器。
4. 任务成功时确认扣点，保存作品；任务失败或超时取消时释放冻结点数并记录失败原因。
5. 成功作品可完整试听、加入队列、收藏和删除。基于服务商权利状态决定是否显示下载/分享。

余额不足时不创建生成任务，只引导用户创建点数购买订单。首版套餐页可创建并查看待支付订单，但不会伪造支付成功，也不会给未支付订单发放点数。后续真实支付接入使用同一订单状态机：`pending -> paid -> credited`，重复回调必须幂等。

## 页面与界面

网站播放器与 Windows 本地播放器采用一致的“暗色唱片室”视觉语言：深灰背景、暖红强调色、圆角专辑封面和半透明面板。

- 宽屏：左侧导航、中心内容区、固定底部迷你播放器。
- 窄屏：底部导航和固定迷你播放器，保持相同色彩与组件语言。
- 首页：音乐搜索、热门提示、创作模板，以及“搜索音乐”“AI 写歌”入口。
- 搜索：按歌名、歌手和专辑检索；每个结果标明来源，提供授权预览、原平台链接和收藏。
- AI 写歌工作台：模型选择、提示词/歌词表单、点数报价、余额、提交动作和任务进度。
- 我的作品：完整试听、作品元数据、任务状态和继续创作相似版本的入口。
- 账户中心：账户资料、余额、点数流水、订单、收藏和作品。

底部迷你播放器展示封面、曲名、播放/暂停、上一首/下一首、进度和音量。展开后的沉浸式播放页展示大封面、完整控制、循环/随机、播放队列和歌词面板。队列可以同时容纳用户的 AI 完整作品与外部授权预览；预览结束自动切换下一项。歌词仅在合法可用时显示，缺失时不编造内容。

## 异常处理与安全

- 未登录的创作、收藏或购买操作引导至登录。
- 搜索源或预览不可用时，保留基本结果与来源链接，并显示可恢复提示。
- 生成服务异常、超时或回调无效时，任务标记失败并释放冻结点数；状态更新必须幂等。
- 任务查询和作品播放必须验证当前用户拥有访问权；管理配置仅限管理员。
- 表单做长度、枚举和敏感内容策略校验；后端对生成、登录和搜索接口限流。

## 验收与测试

- 注册、登录、会话续期和访问控制可靠工作。
- 搜索结果明确标注来源；站内只播放授权预览，完整版通过来源链接打开。
- 每个启用的 AI 服务商都可创建、查询并完成（或明确失败）任务；适配器输出规范化作品数据。
- 点数冻结、成功扣减、失败退款、余额不足和重复状态回调均保持正确余额。
- 待支付订单不增加余额；未来支付回调可幂等地更新订单和发放点数。
- AI 完整作品可在与 Windows 版本一致的深色唱片室 UI 中播放、加入队列和管理；外部预览结束时队列正确前进。
- 宽屏左侧导航/底部播放器与移动端底部导航/迷你播放器均可用。
