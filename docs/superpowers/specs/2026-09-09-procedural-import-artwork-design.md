# 导入歌曲程序化封面设计

## 目标

用户导入的音频没有内嵌封面时，应用在导入阶段自动生成原创封面，并将其与歌曲一起持久化。已有内嵌封面始终保留，歌词导入和播放逻辑不作改变。

## 行为

- 文档导入和传输接力导入统一经过 `FileImportService`；系统音乐资料库导入经过 `SystemLibraryImporter`。两个入口使用同一个生成器。
- 先读取音频内嵌元数据并解析文件名回退信息，再决定封面来源。
- 内嵌封面非空时直接保存，不调用程序化生成器。
- 内嵌封面缺失时，以歌曲标题、歌手和内容指纹为输入生成 768×768 的不透明 JPEG。
- 相同输入必须得到稳定一致的视觉结果；不同音频即使标题相同，也可通过内容指纹形成不同细节。
- 生成失败时不阻止歌曲导入，歌曲继续使用现有占位图。

## 视觉方案

封面采用深色渐变背景、唱片圆盘、中心标签、音频波形/节奏刻度和标题首字符构成。颜色由 SHA-256 摘要确定，不使用网络、模型或第三方图片，避免版权素材依赖。

## 性能与存储

- 单张只执行一次固定尺寸位图绘制和 JPEG 编码，不分析音频内容。
- 批量导入按现有顺序逐首生成，不引入并发内存峰值。
- 生成文件保存在歌曲沙盒目录 `artwork-generated.jpg`，数据库仅保存路径。

## 测试

- 缺少内嵌封面时会生成并持久化封面。
- 已有内嵌封面时不会被生成图覆盖。
- 生成器输出可解码、尺寸正确且不带透明通道。
- 相同输入输出稳定，不同种子输出不同。
- 生成器失败不会导致音频导入失败。
- 系统音乐资料库项目缺少封面时同样生成，且保留系统已有封面。
