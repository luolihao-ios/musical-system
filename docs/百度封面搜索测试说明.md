# 百度封面搜索测试版

更新日期：2026 年 10 月 21 日。

## 本版功能

导入完成后立即显示已有封面或程序化封面，音频导入不等待网络。后台顺序处理缺失封面或 `artwork-generated.jpg` 占位封面；每首最多两轮搜索，优先搜索“歌名 歌曲 封面”，没有可用结果再搜索“歌手 专辑 封面”。查询移除 Live、Cover 等括号内版本说明，不用音频时长筛掉封面。同名候选优先同歌手、同专辑，允许同名歌曲的其他版本。

封面来源固定为用户选定的百度官方搜索 API，不自动回退到其他平台，也不抓取百度网页内部接口。调用 `POST https://qianfan.baidubce.com/v2/ai_search/web_search`，搜索版本为 `baidu_search_v2`，图片模态最多返回八个候选，不调用大模型生成回答。

官方参数文档：https://ai.baidu.com/ai-doc/AppBuilder/pmaxd1hvy

## 手机上的配置和测试

1. 在百度智能云/AppBuilder 开通“百度搜索”服务并取得 API Key。注意不是“相同/相似图片搜索”自建图库服务，也不是 Music Story 密钥。
2. 打开播放器“设置 → 封面搜索设置”，输入自己的测试 API Key，点击“保存密钥并补全封面”。密钥保存在本机钥匙串，不提交到 Git，也不打包进 IPA。不要在聊天或问题日志里粘贴密钥。
3. 使用“重新查找缺失封面”处理已有歌曲，或者从“文件”新导入歌曲。搜索时可继续播放；页面显示处理结果，并可暂停。
4. 先测试少量歌曲，观察补齐数量和具体封面。普通内嵌封面、伴随封面和用户自选封面会保留，不在自动补全时替换。

每首搜索设置约十四秒总预算，单次关键词请求最多五秒、单张图片请求最多四秒；每个关键词最多尝试两张图片。后台一次查询一首，避免批量导入时并发堆积；搜索请求间隔至少约 1.1 秒。失败歌曲一小时内不自动重试，可手动重新查找。相同歌名/歌手的成功结果在会话内复用，内存缓存最多十六项。未配置、鉴权失败或额度不足时明确显示原因，不伪装成“没有封面”。

图片最大下载 4MB，成功解码后缩到最长边 800 像素；过小或长宽比明显不适合封面的图跳过。结果以独立文件保存，旁边的 `source.json` 保留图片地址、原网页地址、候选标题和歌名/歌手专辑替代类型，不改变原音频标签。正在播放的歌曲会刷新封面，保持播放位置与音频引擎不变。

## 歌词改为按需查询

导入、扫描和互传打开应用均不再自动检索歌词。已有同名 LRC 照常使用；没有歌词时，用户在播放页点击“查找歌词”才请求现有歌词服务，且该请求不会查询封面。查询成功后保存本地歌词，已有歌词时不重复查询。

## 验证边界

自动化测试使用固定返回数据验证请求格式、图片解析、歌名放宽匹配、生成封面替换、真实封面保护、删除歌曲时的延迟返回、播放状态保持及按需歌词流程。模拟测试成功不能证明百度真实服务的命中率或大陆网络时延。

项目没有自带百度密钥，当前无法执行带凭据的真实搜索。密钥配置后才能验证真实封面效果。搜索接口的使用权限与结果图片的版权是两件事；测试版保留来源信息，不将“百度返回了图片”描述成素材已获得通用商业使用授权。公开发布前须根据来源条款确认展示及缓存范围。

统一给所有用户提供搜索时，应由后端保存运营方的密钥并控制额度；此测试版使用各测试者自己的密钥，不具备统一服务端密钥分发能力。
