## 已完成功能

### 音乐导入与资料库

- 从“文件”批量导入本地音频及同名 LRC 歌词。
- 支持读取音频内嵌标题、歌手、专辑和封面，并在缺少元数据时回退到文件名解析。
- 支持授权读取设备音乐资料库中具有本地资源地址的歌曲。
- 支持从爱乐互传共享容器扫描并导入音乐；已增加真机文件扫描诊断记录。
- 文件夹授权使用 iOS 支持的书签格式持久化，不使用仅限 macOS 的安全范围书签选项。
- 本地音频扫描改为只由用户主动触发，启动时不再自动重扫；导入任务互斥，避免同一批文件并发处理。
- 程序化封面绘制增加逐首内存释放，并在诊断日志中记录每首歌曲导入前后的状态。
- 没有内嵌封面时，根据歌曲稳定标识、标题和歌手程序化生成不透明 JPEG 封面；已有封面保持不变。
- 不使用 AI、联网封面搜索或歌词生成。

### 播放与交互

- 音乐库、搜索、专辑、歌手、文件夹和播放队列共用统一播放状态。
- 支持切歌、上一首、下一首、播放队列、循环和随机播放。
- 支持后台播放、锁屏与耳机媒体控制。
- 支持同步歌词、点击歌词跳转、用户拖动时暂停自动跟随。
- 播放页支持唱片视图与歌词视图切换，Mini Player 可进入完整播放页。
- 修复导入后播放资源、歌曲信息、歌词、进度和时长不同步的问题。

### 资料库管理与稳定性

- 支持歌曲搜索、最近播放、喜欢、专辑、歌手、来源和自建歌单。
- 支持歌单创建、改名、删除、歌曲增删和拖动排序。
- 支持删除已导入歌曲，并改进迷你播放器的显示与关闭行为。
- 对容器路径变化、重复导入、共享文件迁移和生产监听器测试隔离进行了修复。

### 发布能力

- GitHub Actions 可运行模拟器测试并生成未签名 IPA。
- App Store 工作流可导入分发证书和描述文件、验证 App Group 权限、导出 IPA，并通过 App Store Connect API 验证和上传。
- 签名材料只写入临时目录和临时钥匙串，任务结束后清理。
