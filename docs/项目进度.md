## 已完成功能

### 音乐导入与资料库

- 从“文件”批量导入本地音频及同名 LRC 歌词。
- 支持读取音频内嵌标题、歌手、专辑和封面，并在缺少元数据时回退到文件名解析。
- 支持授权读取设备音乐资料库中具有本地资源地址的歌曲。
- 支持从爱乐互传共享容器扫描并导入音乐；已增加真机文件扫描诊断记录。
- 文件夹授权使用 iOS 支持的书签格式持久化，不使用仅限 macOS 的安全范围书签选项。
- 本地音频扫描改为只由用户主动触发，启动时不再自动重扫；导入任务互斥，避免同一批文件并发处理。
- 程序化封面绘制增加逐首内存释放，并在诊断日志中记录每首歌曲导入前后的状态。
- 播放链路增加独立诊断日志，记录点击歌曲、音频资源加载、AVPlayer 可播放性和系统媒体封面处理结果。
- 音频加载失败时自动停止并清空当前播放状态，避免失效资源导致播放器停留在半初始化状态。
- 播放页和系统媒体控制使用限尺寸封面，避免超大或异常图片造成内存压力。
- 程序化封面继续在 App 内显示，但暂不提交到锁屏系统媒体信息，规避系统媒体封面处理导致的崩溃路径。
- 没有内嵌封面时，根据歌曲稳定标识、标题和歌手程序化生成不透明 JPEG 封面；已有封面保持不变。
- 不使用 AI、联网封面搜索或歌词生成。

### 播放与交互

- 音乐库、搜索、专辑、歌手、文件夹和播放队列共用统一播放状态。
- 支持切歌、上一首、下一首、播放队列、循环和随机播放。
- 支持后台播放、锁屏与耳机媒体控制。
- 支持同步歌词、点击歌词跳转、用户拖动时暂停自动跟随。
- 播放页支持唱片视图与歌词视图切换，Mini Player 可进入完整播放页。
- 播放详情页默认使用当前歌曲的大尺寸封面；无封面时回退到唱片视图，切歌后自动重置展示内容。
- Mini Player 作为底部停靠层贴住应用底部，支持按手指位置跟手展开和收起：上滑松手进入播放详情页，下滑超过可用距离约三分之一后松手关闭，未达到阈值会回弹。
- 播放详情页的歌词页右上角可回到同一张大封面，不会退回缩小唱片；播放时动态声波叠加在封面原有静态声波位置，暂停时保持静止，不在歌曲名下方另加一组。
- 修复导入后播放资源、歌曲信息、歌词、进度和时长不同步的问题。

## App Store Connect 上传前构建号检查清单

只有准备上传到 App Store Connect/TestFlight 的构建，才需要执行以下构建号检查；本地调试、模拟器测试以及不上传的普通构建，不需要为了每次构建都递增构建号：

1. 在 `ios-app/project.yml` 中递增 `CURRENT_PROJECT_VERSION`，构建号必须大于 App Store Connect 中该 Bundle ID 最近一次成功上传的构建号。
2. 同一个构建号一旦成功上传，即使只是重新上传或重新执行上传工作流，也不能再次使用；必须先递增后再构建。未上传的本地构建可以继续使用当前构建号。
3. `MARKETING_VERSION`（例如 `0.2`）和 `CURRENT_PROJECT_VERSION`（例如 `36`）是两个不同字段；本次上传版本应记录为 `0.2 (36)`。
4. 提交并推送包含新构建号的代码后，再从该提交启动 GitHub Actions；不要使用旧提交或旧 IPA 重试上传。仅做本地验证时无需修改构建号。
5. GitHub Actions 的运行编号只用于定位工作流，不能替代 App 的构建号。

如果 App Store Connect 返回“bundle version must be higher than previously uploaded version”，说明上传前的构建号已经被使用，应该递增 `CURRENT_PROJECT_VERSION`、更新本文件中的版本记录，再重新构建上传。
