# file send 核心功能宣传图

用户于本轮明确要求先看五张带真实运行截图的 iPhone 完整宣传图。当前禁止上传素材库或修改产品页图片；只有用户看图后再次明确要求上传，才可调用上传操作。

每张宣传图只表达一个功能，画面主体必须是云端模拟器捕获的真实 App 界面。背景和排版使用内置图像生成工具制作，禁止补造按钮、状态、评价或未实现的功能。

## 功能与文案

1. 连接：**手机电脑，轻松互传**。副标题：同一 Wi-Fi · 浏览器打开即连。界面展示地址、访问码及操作提示。
2. 接收：**批量接收，进度清晰**。副标题：多个文件 · 逐个查看传输状态。界面展示多文件接收卡片及各自进度。
3. 发送：**手机文件，发送到电脑**。副标题：选择文件与媒体 · 电脑统一接收。界面展示已选文件和发送按钮。
4. 编辑：**发送前，随时整理**。副标题：查看已选文件 · 移除不需要的项目。界面展示编辑状态和删除操作。
5. 完成：**传输完成，有序保存**。副标题：按日期归档 · 随时到“文件”查看。界面展示完成状态及保存目录。

iPhone 使用五张；Duo 和 iPad 各使用前四张，并使用各设备自己的真实页面比例。页首图突出浏览器连接与双向传输；搜索结果图突出选择、发送和接收，采用与页首不同构图。

## 视觉提示词

统一使用深靛蓝、紫色与克制青色光线，边缘半透明玻璃文件夹与流动丝带，中下方浅薰衣草色安静背景。顶部约 22% 安排品牌 `file send`、白色大标题及浅色副标题。下方以实际截图作为最大视觉主体，正面比例、界面清晰、不倾斜、不拉伸、不补造控件。全画布不透明、无黑边。不得出现 Windows/Android 状态栏、广告水印或评分徽章。

生成分两步：先由内置图像生成工具制作无界面的功能文案版式，再将真实运行截图按原比例直接排入，避免生成模型重画界面文字和按钮；最终转换为 Apple 要求的精确尺寸及 RGB 不透明 PNG。完整十五张交付素材将使用 `文件验收清单.json`，当前五张预览使用独立的 `iPhone预览验收清单.json`，不能当作已上传的全套素材。

## 2026-10-27 五张 iPhone 预览验收

原始页面来自 GitHub 成功运行 `40315019977` 的 `iphone-preview` 任务，使用项目在 iPhone 17 模拟器上的实际运行界面。演示文件名、地址和进度由仅在 Debug 中启用的截图数据提供；界面使用生产 SwiftUI 组件。没有把 AI 绘制的页面当成实际截图。

五张成图在 `iphone-medium/`，尺寸均为 1206×2622、RGB、不含透明通道。`sources/actual/原图证据.json` 记录云端来源及原图 SHA-256。合成脚本 `scripts/compose_filesend_iphone_previews.cjs` 对成图中的整个截图区域进行逐像素回读，与原图同比例缩放结果一致后才输出成功。五张各有不同 SHA-256，打包在 `file-send-iPhone五张宣传图-预览.zip`。当前没有执行素材库或产品页图片上传。
